City suggestions use a reduced GeoNames cities15000 extract, downloaded 2026-10-28 from https://download.geonames.org/export/dump/cities15000.zip.

Source: GeoNames (https://www.geonames.org/), licensed under Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/).

Modifications: retain capitals and first-/second-level administrative seats (`PPLC`, `PPLA`, `PPLA2`) with names at most 80 characters. Rows contain GeoNames ID, name, ISO country code, latitude, longitude. No venue, price or availability data is included.

The server resolves the starting city through Google Maps, then suggests up to six cities in the same country, 25–250 km away, ordered by approximate straight-line distance. The lower bound keeps the expanded destination suggestions outside the immediate city area. Manual destinations remain unrestricted. GeoNames coverage may be incomplete and coordinates may change; refresh this extract periodically.

Manual origin selection also uses this extract. The public country lookup returns only that country's city records and the country list; country names come from the runtime's English region names. The browser filters typed city names and shows up to three suggestions, ordered by distance when device location is available. Device coordinates remain in component memory and are not sent to the country lookup or stored in the planning draft. Without location permission, suggestions remain available by country and typed city. The existing reverse-geocoding flow for “Use My Location” is unchanged.

For new planning sessions, `/api/country` reads Vercel's `x-vercel-ip-country` header to prefill an approximate country even when browser geolocation is denied. The response contains only a supported country name/code, is private and non-cacheable, and does not return or store the IP address. No external IP lookup service or new key is used. Missing/unknown headers return `country: null`; local development has no automatic estimate unless a test request supplies the header. Existing origin cities, non-default saved countries and subsequent manual edits take precedence. The estimate is editable because VPNs, proxies and travel can make it inaccurate.
